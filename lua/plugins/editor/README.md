# editor - 编辑器增强插件

本目录包含提升编辑体验的插件，包括文件树、自动括号、注释、跳转、多光标等。

## 插件清单

| 文件 | 插件 | 用途 |
|------|------|------|
| `nvim-tree.lua` | `nvim-tree/nvim-tree.lua` | 侧边文件树浏览器 |
| `autopairs.lua` | `windwp/nvim-autopairs` | 自动括号/引号配对 |
| `comment.lua` | `numToStr/Comment.nvim` | 快速注释/取消注释代码块 |
| `illuminate.lua` | `RRethy/vim-illuminate` | 高亮光标下相同单词 |
| `surround.lua` | `kylechui/nvim-surround` | 快速添加/修改/删除环绕字符 |
| `toggleterm.lua` | `akinsho/toggleterm.nvim` | 浮动/底部终端集成 |
| `flash.lua` | `folke/flash.nvim` | 快速跳转（按 `s` 触发） |
| `mini.lua` | `nvim-mini/mini.nvim` | 使用 `Alt+h/j/k/l` 移动选中文本或整行 , `Alt+e`跳出匹配括号|
| `ts-autotag.lua` | `windwp/nvim-ts-autotag` | HTML/JSX 标签自动闭合和重命名 |
| `blankline.lua` | `lukas-reineke/indent-blankline.nvim` | 彩虹缩进参考线 |
| `rainbow.lua` | `HiPhish/rainbow-delimiters.nvim` | 彩虹括号匹配高亮 |
| `ufo.lua` | `kevinhwang91/nvim-ufo` | 基于 Treesitter 的智能代码折叠 |
| `vim-visual-multi.lua` | `mg979/vim-visual-multi` | 多光标/多选区编辑 |
| `yazi.lua` | `mikavilpas/yazi.nvim` | Yazi 终端文件管理器集成 |
| `treesitter.lua` | `nvim-treesitter/nvim-treesitter` | 语法解析与高亮 |
