# ui - 界面与主题插件

本目录包含所有与界面美化、主题、状态栏、通知等相关的插件。

## 插件清单

| 文件 | 插件 | 用途 |
|------|------|------|
| `catppuccin.lua` | `catppuccin/nvim` | 主颜色主题（mocha 深色风格） |
| `lualine.lua` | `nvim-lualine/lualine.nvim` | 底部状态栏，显示模式/分支/诊断/文件名等 |
| `bufferline.lua` | `akinsho/bufferline.nvim` | 顶部 Buffer 标签栏，支持诊断图标和智能关闭 |
| `notify.lua` | `rcarriga/nvim-notify` | 通知消息美化，替代默认 `vim.notify` |
| `dashboard.lua` | `nvimdev/dashboard-nvim` | 启动欢迎界面（Doom 主题风格） |
| `noice.lua` | `folke/noice.nvim` | 命令行、搜索、消息弹窗美化 |
| `deps.lua` | `dressing.nvim` 等 | UI 依赖与辅助美化（选择框、Markdown 渲染等） |
| `neominimap.lua` | `Isrothy/neominimap.nvim` | 代码迷你地图（Minimap） |
| `themify.lua` | `LmanTW/themify.nvim` | 主题管理器，支持多主题切换和实时预览 |
| `web-devicons.lua` | `nvim-tree/nvim-web-devicons` | 文件类型图标支持 |
| `mini-icons.lua` | `echasnovski/mini.icons` | 轻量级图标库 |
