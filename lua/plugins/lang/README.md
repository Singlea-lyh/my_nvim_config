# lang - 语言专项支持插件

本目录包含特定编程语言的增强插件。

## 插件清单

| 文件 | 插件 | 适用语言 | 用途 |
|------|------|----------|------|
| `rustaceanvim.lua` | `mrcjkb/rustaceanvim` | Rust | Rust LSP 深度集成 |
| `rust-crates.lua` | `saecki/crates.nvim` | Rust | Cargo.toml 依赖版本管理 |
| `flutter.lua` | `akinsho/flutter-tools.nvim` | Flutter/Dart | Flutter LSP 和工具集成 |
| `neogen.lua` | `danymat/neogen` | 多语言 | 自动生成函数/类/文件文档注释 |
