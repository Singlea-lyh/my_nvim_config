# ai - AI 辅助插件

本目录包含 AI 代码补全和聊天相关的插件。

## 插件清单

| 文件 | 插件 | 用途 | 状态 |
|------|------|------|------|
| `copilot.lua` | `zbirenbaum/copilot.lua` | GitHub Copilot AI 补全 | 启用 |
| `copilot-chat.lua` | `CopilotC-Nvim/CopilotChat.nvim` | GitHub Copilot 聊天交互 | 启用 |
| `neocodeium.lua` | `monkoose/neocodeium` | Codeium 免费 AI 补全 | 禁用 |
| `llama-vim.lua` | `ggml-org/llama.vim` | llama.cpp 本地模型补全 | 禁用 |

> `neocodeium` 和 `llama.vim` 当前为禁用状态，可按需启用替代 Copilot。
